ABOUT THIS TOOL

Turn XML structures into practical JSON.

Paste an XML document, choose how values should be handled, and convert it without sending the source data to a conversion server.

Elements and arrays

Nested XML elements become nested JSON objects. When sibling elements use the same name, they are grouped into an array automatically.

Attributes and text

XML attributes can be preserved under @attributes. Mixed text is kept under #text so useful content is not silently discarded.

Value detection

Keep all XML values as strings by default, or optionally convert simple numbers, booleans and null values into matching JSON types.

Privacy

Your XML is parsed and converted locally in your browser and is not intentionally uploaded to PocketWorkshop for conversion.
