ABOUT THIS TOOL

Create the common favicon files a website needs.

Start with one square or nearly square logo and generate desktop, browser, Apple and Android icon sizes.

favicon.ico

The ICO file contains several PNG-compressed icon sizes in one file for broad browser and desktop compatibility.

PNG icons

Generate 16×16 and 32×32 browser icons, a 180×180 Apple Touch Icon, and 192×192 plus 512×512 Android icons.

Fit and padding

Use contain to keep the whole logo visible, cover to fill the square, and add padding when the artwork feels too close to the edges.

Privacy

Your image and generated icons are processed locally in your browser and are not intentionally uploaded to PocketWorkshop.
