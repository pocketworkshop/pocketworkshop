ABOUT THIS TOOL

Move images between files and Base64 text.

Useful for CSS, HTML, APIs, JSON payloads, prototypes, debugging and small embedded assets.

Base64 vs Data URL

Raw Base64 is only the encoded data. A Data URL also includes the MIME type and can often be pasted directly into an image source.

File size

Base64 text is usually larger than the original binary file, so it is best suited to smaller images and embedded assets.

Preview Base64

Paste either a full image Data URL or raw Base64. For raw Base64, PocketWorkshop tries common image MIME types automatically.

Privacy

Your image and Base64 text are processed locally in your browser and are not intentionally uploaded to PocketWorkshop.
