ABOUT THIS TOOL

Generate passwords without sending them to a server.

Choose a length and character mix, then create one or many random passwords using your browser's cryptographic random number generator.

Use longer passwords

Length matters. For accounts that support it, longer unique passwords are generally more resistant to guessing than short ones.

Use a password manager

A password manager can help store unique passwords so you do not need to memorize or reuse them across sites.

Strength estimate

The displayed estimate is only a rough indication based on length and the selected character pool. It is not a guarantee of security.

Privacy

Passwords are generated locally with the browser's cryptographic random number generator and are not intentionally uploaded to PocketWorkshop.
