ABOUT THIS TOOL

Turn spreadsheet-style data into JSON.

Paste CSV or similar delimited text, choose how to interpret it, and export clean JSON without uploading the data.

Delimiter detection

Auto detect looks for commas, semicolons, tabs and pipes. You can also choose the delimiter manually.

Quoted fields

Quoted values can contain delimiters, escaped quotes and line breaks, so common exported CSV files work as expected.

Type detection

Optionally convert values such as 42, true, false and null into JSON types instead of leaving everything as text.

Privacy

Your pasted data is processed locally in your browser and is not intentionally uploaded to PocketWorkshop.
