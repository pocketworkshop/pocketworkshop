DATA TOOL

YAML to JSON Converter

Convert common YAML into clean JSON without sending your data to a server.

YAML input 0 characters
JSON output 0 characters

Supports common YAML mappings, sequences, quoted values, comments, flow collections and |/> multiline strings. Advanced YAML features such as anchors, aliases, tags and multiple documents are intentionally rejected instead of being guessed.

ABOUT THIS TOOL

Turn everyday YAML into JSON in your browser.

Useful for configuration files, CI settings, API examples and moving structured data between development tools.

Nested structures

Indented mappings and lists are converted recursively into JSON objects and arrays.

Common YAML syntax

Handles quoted strings, comments, inline arrays and objects, booleans, numbers, null values and multiline text.

JSON controls

Choose two- or four-space indentation, minify the result, or sort object keys alphabetically.

Privacy

Your YAML is parsed and converted locally in your browser and is not intentionally uploaded to PocketWorkshop.
