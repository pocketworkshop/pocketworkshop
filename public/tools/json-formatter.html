ABOUT THIS TOOL

Make JSON readable—or compact.

Check whether JSON is valid, pretty-print it with indentation, minify it, optionally sort keys, and download the result.

Format JSON

Pretty-print compact JSON with 2 spaces, 4 spaces, or tabs so nested objects and arrays are easier to read.

Validate JSON

See whether the input parses correctly. If something is wrong, the tool shows the browser's parse error message.

Common uses

Useful for API responses, configuration files, debugging, copied data, development notes and quick data inspection.

Privacy

Your JSON is processed locally in your browser and is not intentionally uploaded to PocketWorkshop.
