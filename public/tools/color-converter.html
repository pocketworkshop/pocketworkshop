ABOUT THIS TOOL

Move between common web color formats.

Edit HEX, RGB or HSL values and the other formats update automatically.

HEX

Use familiar six-digit web colors such as #22A06B. Three-digit HEX values such as #0A7 are accepted too.

RGB

RGB describes red, green and blue channels from 0 to 255 and is widely used in CSS and digital design.

HSL

HSL separates hue, saturation and lightness, which can be more intuitive when adjusting a color's tone.
