ABOUT THIS TOOL

Tidy up copied text fast.

Remove formatting leftovers, repeated whitespace and duplicate lines without installing anything.

What it cleans

Trim line edges, collapse repeated spaces, reduce blank lines, remove duplicate lines and normalize common smart punctuation.

How to use it

  1. Paste text into the input box.
  2. Choose cleanup options.
  3. Click Clean text.
  4. Copy the result or use it as the next input.

Common uses

Useful for text copied from PDFs, websites, spreadsheets, emails, AI outputs, forms and documents with messy spacing.

Privacy
