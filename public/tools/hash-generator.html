ABOUT THIS TOOL

Create a fingerprint for text or files.

Useful for checksums, comparing content, debugging integrations and verifying that a file has not changed.

Choose an algorithm

Generate SHA-256, SHA-384, SHA-512 or legacy SHA-1 hashes with your browser's built-in cryptography API.

Text or file

Hash pasted text as UTF-8, or select a local file and calculate its digest without uploading it to PocketWorkshop.

HEX and Base64

See the same digest as hexadecimal and Base64 so you can use the format required by your workflow.

Privacy

Your text and files are processed locally in your browser and are not intentionally uploaded to PocketWorkshop.
