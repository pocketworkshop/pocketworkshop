ABOUT THIS TOOL

Fix sideways or upside-down PDF pages.

Rotate an entire PDF or only selected pages, then download a new PDF with the rotation saved.

How to use it

  1. Select a PDF file.
  2. Leave the page box blank for all pages, or enter a range such as 1-3,5.
  3. Choose the rotation angle.
  4. Rotate and download the new PDF.

Selected pages

You can rotate only the pages that need fixing. Other pages keep their existing orientation.

Common uses

Useful for scanned documents, receipts, forms, reports, or PDFs where some pages were saved sideways or upside down.

Privacy

The rotation runs locally in your browser. Your selected PDF is not intentionally uploaded to PocketWorkshop for processing.
