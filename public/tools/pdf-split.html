ABOUT THIS TOOL

Take only the PDF pages you need.

Extract selected pages into a new PDF, or split every page into separate PDF files and download them together as a ZIP.

Extract selected pages

Enter page numbers such as 1-3,5,8-10 to create one new PDF containing only those pages.

Split every page

Use Split every page to ZIP when you want each page saved as its own PDF file. The individual PDFs are packaged together for download.

Common uses

Useful for pulling a form from a larger document, separating scanned pages, sharing only selected pages, or breaking a long PDF into individual files.

Privacy

The splitting process runs locally in your browser. Your selected PDF is not intentionally uploaded to PocketWorkshop for processing.
