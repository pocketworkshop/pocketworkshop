ABOUT THIS TOOL

Generate random values in a custom range.

Choose integers or decimals, set a minimum and maximum, then create one or many values at once.

Integers or decimals

Generate whole numbers, or switch to decimal mode and choose how many decimal places to display.

Unique values

For integer ranges, you can require every generated value to be different as long as the requested count fits the range.

Common uses

Useful for test data, drawings, classroom exercises, simple simulations, randomized lists and quick number selection.

Privacy

Random values are generated locally in your browser using its cryptographic random number generator and are not intentionally uploaded to PocketWorkshop.
