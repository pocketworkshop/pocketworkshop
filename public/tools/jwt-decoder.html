ABOUT THIS TOOL

Inspect JWT contents without sending the token to a decoder service.

Useful when debugging authentication flows, API integrations and token claims during development.

Header

See metadata such as the signing algorithm (alg) and token type (typ) stored in the first JWT segment.

Payload

Read claims such as issuer, subject, audience and custom application data stored in the second segment.

Time claims

Unix timestamps in iat, nbf and exp are displayed as readable dates when possible.

Privacy and verification

The token is decoded locally in your browser. Decoding is not signature verification, so do not treat decoded data as trusted by itself.
