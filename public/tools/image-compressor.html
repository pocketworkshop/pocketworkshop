ABOUT THIS TOOL

Make image files lighter.

Reduce image file size while keeping the original dimensions, with control over output format and quality.

What it does

Re-encodes JPG, PNG, or WebP images in your browser so you can create a smaller file for sharing, storing, or uploading.

How to use it

  1. Choose an image from your device.
  2. Select the output format.
  3. Adjust the quality setting.
  4. Compress the image and compare the new file size before downloading.

Common uses

Useful when a website has an upload limit, when you want smaller email attachments, or when you need lighter images for web pages.

Privacy

Your image is processed locally in your browser and is not intentionally uploaded to PocketWorkshop for compression.
