ABOUT THIS TOOL

Understand what is inside a URL.

Useful for debugging links, APIs, redirects, analytics URLs, tracking parameters and web application routes.

URL parts

See the protocol, hostname, port, host, path, query string, hash fragment and origin separately.

Query parameters

Each query key and value is listed separately, including repeated keys such as tag=one&tag=two.

Copy values

Copy individual URL parts or copy the full parsed result as plain text for debugging and documentation.

Privacy

Your URL is parsed locally in your browser and is not intentionally uploaded to PocketWorkshop.
