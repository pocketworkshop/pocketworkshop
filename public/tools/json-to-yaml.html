ABOUT THIS TOOL

Turn JSON into readable YAML without uploading it.

Useful for configuration files, documentation, APIs, CI workflows and moving structured data between tools.

Nested data

Objects, arrays, strings, numbers, booleans and null values are converted recursively into readable YAML.

Safe strings

Strings that could be confused with YAML numbers, booleans, dates or syntax are quoted automatically.

Formatting controls

Choose two- or four-space indentation, sort object keys, quote every string or add a YAML document marker.

Privacy

Your JSON is parsed and converted locally in your browser and is not intentionally uploaded to PocketWorkshop.
