QR TOOL

QR Code Generator

Turn a URL or text into a QR code and download it as a PNG. The content is processed in your browser.

Tip: test the downloaded code with your phone camera before printing it.

ABOUT THIS TOOL

Create a QR code in seconds.

Paste a web address or type any short text, choose the image size, and download the finished QR code as a PNG.

How to use it

  1. Enter a URL or text.
  2. Choose the output size and error correction level.
  3. Select Generate QR code.
  4. Download the PNG when it looks right.

What is error correction?

Higher levels can make a QR code easier to scan if part of it is damaged or obscured, but they also create a denser code.

Common uses

Useful for websites, menus, event pages, contact information, signs, printed handouts, and quick sharing between devices.

Privacy

Your entered text is used to generate the QR code in your browser and is not intentionally uploaded to PocketWorkshop for processing.
