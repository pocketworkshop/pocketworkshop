ABOUT THIS TOOL

Make XML easier to read and inspect.

Use the formatter for readable indentation, minify XML for compact output, or validate pasted XML before using it elsewhere.

Format XML

Indent nested elements while keeping attributes, comments, CDATA sections, processing instructions and mixed text content intact where possible.

Validate XML

The browser's built-in XML parser checks whether the document is well formed and reports parsing errors when it can.

Minify XML

Remove formatting-only whitespace between elements to create a more compact XML string without sending it to a server.

Privacy

Your XML is processed locally in your browser and is not intentionally uploaded to PocketWorkshop for formatting or validation.
