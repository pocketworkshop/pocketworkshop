ABOUT THIS TOOL

Experiment with JavaScript regular expressions.

Useful for testing patterns before putting them into code, validation rules, search tools or text-processing scripts.

Flags

Toggle global, case-insensitive, multiline, dotAll and Unicode matching. The tester uses JavaScript's built-in RegExp engine.

Capture groups

See numbered capture groups and named groups for each match, along with the character position where the match begins.

Highlighting

Matched sections are highlighted in the preview so you can quickly see what your pattern is selecting.

Privacy

Your pattern and test text are processed locally in your browser and are not intentionally uploaded to PocketWorkshop.
