ABOUT THIS TOOL

Encode and decode URL text in one place.

Convert spaces, symbols and non-ASCII characters to percent-encoded text, or reverse encoded values back to readable text.

URL component

Use this for query values, path pieces and other parts of a URL where reserved characters should be encoded.

Full URL mode

Use full URL mode when you want to preserve URL separators such as :, /, ? and &.

Form style

Form-style encoding uses + for spaces, matching the common application/x-www-form-urlencoded convention.

Privacy

Your text is processed locally in your browser and is not intentionally uploaded to PocketWorkshop.
